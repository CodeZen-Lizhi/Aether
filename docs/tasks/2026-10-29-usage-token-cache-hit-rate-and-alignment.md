# 使用记录 Token 缓存命中率与列对齐

日期：2026-10-29

## 目标

- Tokens 列保持两行：输入 / 输出、缓存读取 / 缓存命中率。
- 缓存命中率只显示百分比，不增加进度条或文字标签。
- 修正全屏及各种窗口尺寸下 Tokens、费用等数值列表头与数据不共线的问题。

## 实现

- `token-normalization.ts` 按 API 格式归一化缓存命中率分母，计算缓存读取 Token 占比。
- 使用记录桌面表格与移动卡片将缓存行右侧的无意义横杠替换为命中率百分比；缓存写入仍保留在悬停说明中。
- Tokens 表头改为右对齐，与输入/输出、缓存读取/命中率及费用等数值内容使用相同右侧边界。

## 验证

- 目标 Vitest：`UsageRecordsTable.spec.ts`、`token-normalization.spec.ts` 共 54 项通过。
- `npm run type-check`、`npm run build` 通过。
- 真实组件 fixture 在 390、840、900、1024、1280、1440、1920、2560、3840 像素宽度检查：390 使用移动卡片，其余尺寸所有可选列的表头与首行内容边界一致；页面无横向溢出。

## 注意

- 缓存写入 Token 不再占用列表缓存行的右侧槽位；需要查看时使用悬停说明或请求详情。
- 全屏宽度下列宽仍按现有规则填满容器，不通过限制列宽解决对齐。
