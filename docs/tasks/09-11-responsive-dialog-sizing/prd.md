# 统一弹窗响应式尺寸

## Goal

所有应用内模态弹窗随所在 APP 内容窗口缩放，在最小窗口下保留清晰的背景空间，在大窗口下受尺寸上限约束，表单、测试结果和操作按钮完整可用。

## Confirmed Facts

- 用户所说的“最小化”按上下文理解为将 APP 缩至最小可用窗口。管理窗口默认 1200×820、最小 900×640；启动窗口最小 740×580，不应混用（`apps/aether-desktop/src-tauri/src/windows.rs:153`、`:154`、`:343`）。
- 共享 `Dialog` 采用 `w-full` 加固定最大宽度档位，桌面最大高度为 `100dvh - 2rem`（`frontend/src/components/ui/dialog/Dialog.vue:37`、`:155`）。在 900×640 下该高度上限为 608px，约占窗口 95%。
- 当前共有 22 个文件直接使用共享 `Dialog`，共 25 个实例，另有经 `AlertDialog` / `ConfirmContainer` 间接使用者；完整清单见 `research/dialog-inventory.md`。
- 供应商新增/编辑使用 `xl`（`frontend/src/features/providers/components/ProviderFormDialog.vue:7`）；模型测试使用 `3xl`，内部图片预览使用 `6xl`（`frontend/src/features/providers/components/provider-tabs/ModelTestDialog.vue:4`、`:753`）。
- 模型新增/编辑目前均已为 `3xl`，旧 PRD 的编辑模式 `4xl` 信息已过时；内部仍有独立视口高度约束（`frontend/src/features/models/components/GlobalModelFormDialog.vue:7`、`:12`、`:250`）。
- 请求回放独立实现，宽度 `max-w-6xl`、高度 `60vh` 至 `85vh`，内容固定左右各半（`frontend/src/features/usage/components/ReplayDialog.vue:13`、`:97`、`:99`、`:177`）。

## Requirements

- R1：所有共享模态框以及独立请求回放使用统一的窗口比例与绝对上限规则，尺寸参照所在 WebView 内容视口，不参照物理屏幕或侧边栏剩余区域。比例具体建议见 design.md，待本轮方案确认。
- R2：供应商新增/编辑采用同一表单档，模型新增/编辑和模型测试采用复杂内容档；图片预览、批量映射、请求回放允许更宽但仍有比例与绝对上限。
- R3：桌面弹窗总高度最多为窗口内容高度的 80%，绝对上限 800px。普通表单高度随内容自然收缩，不强制拉满；长内容在 body 内滚动，标题和操作区持续可见。
- R4：打开弹窗后缩放窗口，立即重新计算布局且不丢失表单输入、当前测试结果或正在进行的测试状态。嵌套弹窗按 APP 视口计算，保持原关闭和层级行为。
- R5：内部多列、代码、错误详情、图片和选择器需适应弹窗可用宽高；禁止依赖横向滚动、裁切字段或缩小字号来满足比例。请求回放保留专用编辑/结果交互，可在窄内容区改为上下排布。
- R6：保留小于 640px 视口下已有移动端底部抽屉形态、安全区和操作顺序；独立回放仍沿用自己的移动端形态并修正溢出。

## Acceptance Criteria

- [ ] AC1 / R1-R2：对清单内每个实例记录档位及静态检查结论；抽屉、下拉和提示不误归为居中模态框，独立回放不遗漏。
- [ ] AC2 / R1-R3：在 900×640 下，供应商表单建议宽约 522px、总高不超过 512px；模型测试建议宽约 666px、总高不超过 512px。大窗口达到各档上限后不再增大。
- [ ] AC3 / R3-R5：供应商新增/编辑、模型新增/编辑、模型测试设置/运行/成功/失败、图片预览、批量映射、确认框、系统导入及回放分别覆盖代表性真实浏览器流程；长内容最后一项、长错误末尾和操作按钮可达。
- [ ] AC4 / R4：同一弹窗保持打开，从 900×640 调至 1440×900 再缩回；尺寸和布局随窗口变化，输入、选择、结果和嵌套关闭行为保持一致。
- [ ] AC5 / R5-R6：840×620、900×640、1024×768、1440×900、1920×1080 及 390×844 下检查共享层边界；代表性复杂内容的 scrollWidth 不大于 clientWidth，没有文本重叠或字段裁切。
- [ ] AC6 / R1-R6：目标文件 lint、前端类型检查及直接相关回归检查通过；浏览器布局证据与原生 APP 验证分别记录，无法执行的流程标记未验证，不以类型检查代替行为验收。

## Out Of Scope

- 侧边详情抽屉、菜单、Popover、Tooltip、系统文件选择器和 OAuth 外部窗口的尺寸改造。
- 后端接口、数据持久化和测试请求业务语义；不更改 APP 主窗口最小尺寸。
- 整体视觉主题、字体缩放、业务表单重写及无关布局重构。
