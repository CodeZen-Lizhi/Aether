# 密钥表单跟随上游问题修复

日期：2026-11-06

## 用户反馈与完成条件

- 倍率来源菜单跑到弹窗外的错误位置：保持锚定触发框，缩放及滚动时不被裁切。
- 新增选择跟随上游仍显示默认倍率 1：未查询时隐藏数字；已有跟随密钥显示真实生效倍率，零值有效。
- 选择跟随后添加，列表仍显示手动：同步成功后列表及刷新重读必须显示服务端真实状态。

## 定位与实现

- 当前共用 Select 已默认 Portal 到 body；Chromium 检查不能复现截图错位，沿用该修复，不新增第二套定位机制。截图来自的桌面运行版本尚未核实。
- `KeyFormDialog` 原来在来源同步后仍发出创建或普通更新的旧快照；父级 `handleKeyChanged` 重读后再次应用旧快照，覆盖列表中的模式和倍率。来源操作后改为不传旧快照，通过既有父级流程重读。新增和编辑同时修复。
- 手动模式保留倍率输入；尚未同步的跟随选择隐藏数字，已有跟随模式展示当前服务端值。
- 后端仍要求查询有效倍率后才保存跟随状态；上游失败保留原模式和倍率，前端明确提示密钥已保存但来源未更新。
- 扩展既有隔离 fixture：真实表单、API 封装及列表控件使用合成数据和会话存储，保留父页面重读后再应用快照的关键顺序。
