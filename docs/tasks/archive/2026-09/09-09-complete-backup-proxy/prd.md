# 补齐完整备份与导入后代理节点显示

## Goal

复现并修复导入后代理节点不可见，完整保存代理、供应商代理关联、设置与供应商密钥信息；保留原子导入导出并同步两分支。

## Requirements

- 完整备份包含代理节点及认证信息、系统默认代理、外部模型代理，以及供应商、Endpoint、渠道 Key 的代理关联。
- 保存供应商配置、模型映射、渠道密钥和认证配置，并补齐渠道账户元数据、状态及用量信息。
- 导入后立即显示最新节点和系统设置；节点加载失败不得显示为没有节点。
- 保持无格式版本门槛、单事务全部提交或全部回滚；不操作用户真实数据库。
- 共用功能同步到 `slim-personal` 与 `codex/tauri-macos`，验证后提交 push，并更新安装包。

## Acceptance Criteria

- [x] 用缓存为空的前端列表复现并修复导入后节点不可见。
- [x] 两个临时实例间恢复手动及离线隧道节点，所有代理引用正确重映射。
- [x] 供应商/模型/Key/系统配置完整往返；新增元数据、统计及凭据得到保留。
- [x] 无效代理引用、凭据错误和后段写入失败时整体失败且数据不变。
- [x] 检查通过，两分支已 push，交付更新安装包。

## Notes

- 用户明确报告导入后一个节点也看不到；不能以已有导入代码代替验收。
