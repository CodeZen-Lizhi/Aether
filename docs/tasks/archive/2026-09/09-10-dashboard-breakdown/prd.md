# 修复仪表盘历史模型和供应商统计

## 目标

仪表盘按真实模型和供应商展示每日成本与分布，历史汇总不能伪装成名为 aggregate 的业务对象；总请求、Token、结算费用和实际成本保持准确。

## 验收

- [x] 已保存的历史模型 / 供应商分组能够展示，原始记录存在时可补足分组。
- [x] 历史汇总、实时记录、日期空洞及用户范围查询不重复或漏计。
- [x] 只有总量而没有明细的旧数据仍保留总量，并明确显示明细不完整。
- [x] 回归测试、API 与页面验证通过，共用代码同步两分支并交付新安装包。

## 边界

使用隔离合成数据库，不改用户真实数据；保持现有无版本、原子导入导出及客户端差异。
