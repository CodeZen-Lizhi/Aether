# 使用记录活跃请求状态收敛

日期：2026-10-29

## 目标

- 等待中或传输中的请求只显示单个“进行中”状态，不再同时显示请求类型和客户端传输方式。
- 请求完成、失败或取消后，才展示请求类型、终态和传输方式。

## 实现

- `UsageRecordsTable.vue` 增加统一的活跃请求判断；桌面表格与移动卡片在活跃态隐藏请求类型及传输徽章，只保留一个“进行中”徽章。
- 终态记录继续按原有顺序展示请求类型、失败/取消状态和客户端传输方式。

## 验证

- `UsageRecordsTable.spec.ts` 50 项通过，覆盖等待中与传输中的桌面、移动布局，不再渲染类型或传输徽章。
- TypeScript 类型检查通过。
- 真实组件页面在 1435px 与 390px 检查：两个活跃请求均只显示“进行中”，完成、失败和取消记录仍保留类型与传输；页面及卡片容器无横向溢出。
