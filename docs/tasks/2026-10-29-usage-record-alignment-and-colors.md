# 使用记录对齐与语义色调整

日期：2026-10-29

## 目标

- 使用记录所有列头与单元格内容统一左对齐，修正 Tokens、费用和耗时列右对齐造成的错位。
- 为下方记录中的请求类型、生命周期和传输标签增加稳定、低饱和且可区分的语义色。
- 为下方记录中的 Tokens、费用以及端到端首字、总耗时和输出速度建立更清晰的视觉层级。

## 实现

- `UsageRecordsTable.vue` 的类型/状态、Tokens、费用和性能列统一改为左对齐，并移除内部的 `justify-end` / `items-end` 布局。
- 请求类型按对话、会话压缩、图像、视频、实时会话和未知类型映射不同色系；失败、等待、传输中和取消沿用生命周期语义色；流式、标准与 WebSocket 使用独立传输色。
- Tokens 的输入、输出、缓存读取和命中率分别着色；性能首字、总耗时和输出速度分别使用琥珀、蓝、绿色；非零费用使用主蓝强调，零值保持弱化。以上颜色只作用于记录内容，表头保持正常文字色。
- `usage-type.html` fixture 补齐代表性费用和耗时数据，用于真实组件视觉验收。

## 验证

- `UsageRecordsTable.spec.ts` 47 项通过；`npm run type-check` 通过。
- 真实组件 fixture 在 1920×1080、1024×768 和 390×844 检查：8 个表头均为左对齐，数据起点与表头一致，页面和列表无横向溢出；390 宽正确切换卡片视图。
- 浅色和深色主题下检查请求类型、生命周期、传输、Tokens、性能和费用色；颜色随主题切换且关键文本保持可读。
