# 重规划设置页与精简功能入口

## Goal

把设置页从七块纵向配置面板改为四类任务导向的设置，减少需要理解的参数，让代理、记录保留、备份和诊断容易查找，并区分配置修改与维护操作。

## Background

- 用户认为整个设置页布局难看、功能过多，要求重新规划并判断哪些功能需要保留。
- 2026-09-12 用户明确删除设置页中的主题、语言、时区编辑入口；主题和语言继续用右上角快捷切换；时区沿用现状，无需新增处理。其余取舍交由本次规划。
- 当前有七类分区，折叠时仍显示保存及立即清理操作；清理策略有 11 个数字参数，基础配置混合限速、过期 Key 行为和四个兼容选项。证据见 research/settings-inventory.md。

## Requirements

### R1. 移除重复偏好编辑

- 设置页面和账号设置不再展示主题、语言、时区表单，移除表单专有加载、保存及无引用组件。
- 右上角主题/语言快捷切换及持久化方式保持；不重置已有偏好，不改变日期、统计区间及默认时区。
- 桌面 `/admin/settings` 继续跳转系统设置；Web 账号、密码、登录设备保留。

### R2. 四类导航

- 分类为「连接与启动」「记录与存储」「备份与恢复」「高级与诊断」，默认打开第一类；Web 第一类名为「网络连接」且无桌面项。
- 页面内窄分类导航配合单一内容区，替代右侧滚动目录和七张大卡片。窄窗口改顶部分类选择器。
- 内容使用分组标题、对齐设置行和分隔线，沿用全局外壳、字体、语义色与图标；不新增搜索、收藏、模式切换或空的常规分类。
- 分类切换保留输入及保存状态，浏览器前进/后退和旧分区链接仍能定位。

### R3. 连接与启动

- 常用层：默认出站代理、代理节点增改删/测试、登录 Mac 时自动启动。
- 网关端口置于折叠行，收起显示当前值；保存继续明确提示自动重启。
- 启停和重启沿用右上角菜单；目录和日志归入诊断。默认代理保存与节点操作保持独立目标和反馈。

### R4. 记录与存储

- 常用层：记录内容级别、自动清理、请求/响应内容保留天数、请求记录保留天数。
- 内容保留对应 `compressed_log_retention_days`，超过后删除内容；`detail_log_retention_days` 只决定压缩时点，不得误称为删除期限。
- 次级选项分为「详细保留策略」和「敏感请求头」：前者收纳压缩时点、请求头及其他记录保留期，后者维护脱敏规则，与原保存边界对应。
- 三个清理批次参数从前端编辑项中删除，后台沿用现值和默认值；普通保存不得将它们写回默认值。
- 按策略立即清理及执行历史移到高级诊断；自动清理开关保留即时保存行为。

### R5. 备份与恢复

- 完整备份作为主操作，显示创建备份与恢复备份；仅配置导入导出置于「配置迁移」次级入口。
- 保留两类备份各自范围、预览、合并/覆盖选择、进度及结果反馈，不合并成同一种恢复行为。
- 本分类不放清空配置或记录等维护动作。

### R6. 高级与诊断

- 请求兼容：全局格式转换、同步生图心跳、标准文本非流式心跳、Cyber 错误继续转移，保留行为及现值。
- 密钥默认规则：默认请求限速、过期独立 Key 处理。
- 诊断：真实版本、桌面专属目录和按需读取的日志。版本可同时作为分类导航底部简短信息，不占独立卡片。
- 数据维护为默认折叠的单一入口，包含按策略清理、执行历史及原有五种清空操作。危险色只用于相关动作，并保留精确范围确认。
- 不把清空统计聚合描述为无损修复，不承诺仅凭剩余原始记录恢复全部历史统计。

### R7. 保存与反馈

- 沿用原独立保存边界，只有被编辑的分组显示保存/取消，反馈处理中、成功或错误；无跨全部配置的保存按钮。
- 折叠标题不放保存、开关或危险操作；自启动和自动清理开关在内容行中。
- 保存只提交对应可编辑字段，成功与失败按实际结果反馈；不得重置其他分组，失败保留输入可重试。
- 新增文案覆盖英文，快捷切换后导航和操作仍清楚可达。

## Acceptance Criteria

- [ ] AC1 (R1): 设置表单无主题、语言、时区编辑项；顶部切换及刷新保留正常，日期与时区未重置。
- [ ] AC2 (R2): 四类可切换且输入不丢；旧 hash、前进/后退定位正确。
- [ ] AC3 (R3): 默认代理保存、节点测试及编辑测试可用；桌面自启动和端口操作保持，非法端口被校验。
- [ ] AC4 (R4): 记录级别及两项常用期限保存后刷新一致；三个批次输入消失，普通保存不提交它们。
- [ ] AC5 (R5): 完整备份与配置迁移有独立准确范围，恢复预览、取消和进度可用。
- [ ] AC6 (R6): 兼容选项和 Key 规则可达；维护默认折叠且保留范围确认；日志按需读取。
- [ ] AC7 (R7): 保存反馈匹配分组，失败保留输入，其他组不被提交；局部成功不误报全部完成。
- [ ] AC8 (R2/R7): 840x620、1024x768、1440x900、390x844 无字段裁切或横向溢出；明暗主题、中英文、键盘可用。
- [ ] AC9 (R1/R3): Web 无桌面 IPC 控件或空占位，账号功能可达；桌面旧偏好路由兼容。

## Out Of Scope

- 不提交、push 或发布，除非后续得到相应授权。
- 不删除后端能力、迁移数据库、重置配置或改变网关鉴权。
- 不新增清理预设、自动调整保留期或改变备份格式/导入语义。
- 不重做其他管理页及通用组件，不改已有版本或锁文件变更。

## Planning Status

PRD、设计、实施顺序和上下文清单齐备。用户于 2026-09-12 明确回复「开始修改」，批准按本方案实施及验证。
