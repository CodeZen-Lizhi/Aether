# 供应商列表移除冗余详情按钮

日期：2026-10-29

## 目标

- 移除供应商操作列中无实际价值的“查看详情”眼睛按钮。
- 保留桌面整行点击和移动端整卡点击打开详情。

## 实现

- 从 `ProviderTableRow.vue` 删除查看按钮、Eye 图标和不再使用的 `viewDetail` 事件。
- 从 `ProviderMobileCard.vue` 删除重复的查看按钮，保留卡片根节点打开详情的事件。
- 清理两个组件中不再使用的脚本声明。

## 验证

- 目标 Vitest 8 项、TypeScript 类型检查和 ESLint 通过。
- 真实表格 fixture 在 900、1024、1280、1440、1920、2560、3840 像素宽度检查：操作列只剩 4 个按钮，无“查看详情”入口、按钮未溢出、表格贴合容器且页面无横向滚动。
