# 重设计个人网关设置页与固定布局

## Goal

把系统设置变成适合个人网关的紧凑工具页面：常用操作容易找到，其余配置按需进入；从 APP 最小窗口到最大化保持相同内容结构和视觉风格。

## Background

- 常用项是出站代理、开机启动、端口、创建备份和恢复备份；用户允许设计者调整组织方案。
- 2026-09-12 用户先要求规划，尤其要求缩放窗口时布局不变，主要改变空白空间，并与 APP 整体风格一致；随后明确批准实施。
- 管理窗口默认 1200x820、最小 900x640，未设置最大尺寸：`apps/aether-desktop/src-tauri/src/windows.rs:153`。默认端口 8084：`apps/aether-desktop/src-tauri/src/config.rs:10`，展示须读取实际配置。
- 当前四类导航在内容宽度小于 760px 时改成下拉框，端口折叠、代理节点列表常驻：`frontend/src/views/admin/SystemSettings.vue:1`、`frontend/src/views/admin/system-settings/settings.css:56`、`frontend/src/desktop/DesktopSettings.vue:110`、`frontend/src/views/admin/system-settings/ProxyConfigSection.vue:60`。
- 全局标题用衬线体、控件用无衬线体：`frontend/src/style.css:360`。本方案降低设置分组的衬线字体密度，保留页标题与 APP 的关系。

## Requirements

### R1. 个人使用优先

- 首页直接展示出站代理、实际网关端口、开机启动、创建备份和恢复备份，无需先选择分类。
- 代理选择保留直连；节点增删改与测试从紧邻选择器的管理入口进入。
- 端口直接可见可编辑，明确保存后重启；不强制覆盖为 8084。
- 备份是主动操作，不是必填设置或首次运行任务；保留准确范围及恢复预览。

### R2. 稳定布局

- 900x640 至显示器最大化范围内，主页、入口、分组顺序和设置行结构一致。
- 不因窗口缩小而将导航改成下拉框、自动折叠功能、将左右设置行切换成上下布局、缩小字体或整体缩放页面。
- 外边距、组间距、行留白和中间弹性空间承担尺寸变化；大窗口限制内容宽度，避免标签与控件相隔过远。
- 最小窗口中文正常初始态，五项常用入口和高级入口首屏可达。英文、编辑、报错及长名称可自然增高并纵向滚动，不裁切或改变列关系。
- 用户主动展开或进入功能允许内容高度变化；小于 APP 最小尺寸的 Web 兼容样式不得影响桌面范围。

### R3. 层级与流程

- 首页仅「网关」「数据备份」两组；标题行有固定「高级设置」入口，页尾有版本。
- 「代理管理」「高级设置」使用同一内容框架的二级页面和返回入口，不新增页面内侧栏。
- 高级页面按需展开记录与清理、请求兼容、密钥规则、配置迁移、诊断、数据维护；危险操作保留范围确认。
- 返回、切换和浏览器前进后退保留草稿；旧 query/hash 可定位对应位置。

### R4. 风格一致

- 复用 Aether 白底、蓝色交互色、明暗主题、现有组件和 Lucide 图标，不新增主题或字体资源。
- 页标题延续现有字体；分组、标签、说明和控件用无衬线体，字号不随窗口缩放，字距为 0。
- 使用未装饰成卡片的分组、细分隔线和统一对齐轴，不增加概览卡片、状态横幅、装饰背景或重复标题。
- 控件尺寸一致，悬停、焦点、禁用及错误可区分；图标按钮有可访问名称和提示。

### R5. 行为兼容

- 保留配置现值、默认值、后端能力、API、IPC、备份格式和恢复语义；隐藏字段不写回默认值。
- 保持 proxy/basic/log/cleanup 分组保存，端口、自启动沿用桌面独立调用；部分失败保留可重试输入。
- Web 不展示桌面端口、自启动和命令，不留空分组；新文案纳入既有中英文映射，主题语言入口仍在顶部。

## Acceptance Criteria

- [x] AC1 (R1/R3): 首页五项常用入口可用；节点管理及高级设置一跳可达，返回后草稿保留。浏览器配合隔离 API/桌面命令 fixture 验证。
- [ ] AC2 (R2): 900x640、1024x768、1200x820、1440x900、1920x1080 及当前显示器最大化时结构、控件顺序和左右列关系相同；连续拖动不切换导航或分组模式。
- [x] AC3 (R2/R4): 最小窗口中文初始态五项入口与高级入口首屏可达，无横向溢出、遮挡或裁切；大窗口不新增列或无限拉长表单。已通过浏览器实际 DOM 测量与截图检查。
- [ ] AC4 (R2/R4): 明暗主题、中英文、长名称、保存中和错误态可读可操作，键盘焦点无遮挡；动态状态允许纵向增长。
- [ ] AC5 (R1/R5): 代理保存、节点测试编辑、端口校验、自启动、备份导出及恢复预览保留真实调用与结果；保存刷新一致，失败不误报成功。
- [x] AC6 (R3/R5): 旧 query/hash 与前进后退正确；高级保存不改隐藏批次参数或其他组；Web 无桌面 IPC 控件。

AC2 的五档浏览器尺寸及连续缩放已通过，原生最大化待验收；AC4 的明暗、中英文、长名称、错误态已检查，原生焦点和宿主字体待验收；AC5 的隔离 HTTP 流程及桌面 fixture 已通过，实际端口重启和自启动 IPC 待验收。完整证据见 `validation.md`，未勾选项不代表已完成原生检查。

## Out Of Scope

- 不重新选择运行默认值，不删除后端配置，不改数据库、鉴权、端口绑定范围、备份格式或恢复规则。
- 不重设计全局导航和其他管理页，不改原生最小窗口尺寸。
- 不发布、不操作真实运行配置或恢复/清空个人数据。用户已追加授权提交、push 和本机打包。
