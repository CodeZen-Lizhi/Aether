# 模型测试统一工作区

日期：2026-10-29

## 目标

- 模型测试的开始、进行中、主动停止和最终结果始终保留在同一个“模型测试”弹窗内。
- 删除结果态重复出现的“返回”和“关闭”，以及容易误解的“取消”文案。
- 改善测试记录、状态、耗时和失败详情的视觉层级。

## 实现

- `ModelTestDialog.vue` 移除 `setup / testing / result` 三段互斥视图，改为固定的“测试配置 + 测试记录”结构。
- 配置区默认展开；开始测试或展示已有结果时自动收起为端点、Key、映射摘要，仍可在原处展开查看；测试期间配置控件锁定。
- 页脚按状态提供“关闭 / 开始测试”“关闭 / 停止测试”“关闭 / 重新测试”，不再渲染“返回”。
- 运行区展示实时进度、请求 ID 和最近候选；结果区使用成功/失败语义色、状态徽标、耗时强调色及详情表。
- `useModelTest.ts` 新增 `cancelTest()`，中止当前请求、保留已有追踪记录，并通过运行令牌忽略停止后迟到的响应。
- 预览 fixture 使用正式组件模拟开始、进行中、停止、成功和失败，预览与成品共用同一套状态逻辑。

## 验证

- 目标 Vitest 3 个文件、5 项通过。
- `npm run type-check`、目标 ESLint、`npm run build` 通过。
- 真实组件浏览器检查覆盖 1200×900、900×640、390×844 和浅深主题；配置/记录始终同屏，页面与弹窗均无横向溢出。
- 实际执行“开始 → 进行中 → 成功”和“开始 → 停止”：配置自动收起，结果表/停止记录在同一弹窗出现；结果态只有“关闭 / 重新测试”，测试中只有“关闭 / 停止测试”，无“返回”。
