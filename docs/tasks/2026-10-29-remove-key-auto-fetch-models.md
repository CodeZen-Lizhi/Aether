# 移除密钥自动获取上游模型

## 目标

新增、编辑密钥时不再提供自动获取上游模型配置；删除仅服务于该功能的网关 Worker、即时拉取逻辑、请求字段、前端状态和共享实现。数据库结构及备份兼容字段保持不变。

## 边界

- 保留模型映射和模型权限中的手动上游模型查询。
- 不迁移或改写现有数据库列；新密钥沿用 `auto_fetch_models` 的数据库默认关闭值。
- 旧客户端即使继续发送退役字段，服务端也忽略该字段且不发起上游请求。
- 旧数据库值可用于备份恢复，但不再驱动任何后台或保存时行为。

## 实施

- 密钥表单、模型权限和详情状态移除自动同步/锁定模型 UI。
- 删除网关 `model_fetch` 运行时、任务注册、密钥写入时同步和专用仓储写入方法。
- 删除 `aether-model-fetch` 中仅供自动关联、过滤和启动调度使用的实现。
- 保留 `POST /api/admin/provider-query/models`，用于映射与权限弹窗按需查询。
