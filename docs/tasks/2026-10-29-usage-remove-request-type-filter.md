# 使用记录移除请求类型筛选

日期：2026-10-29

## 目标

- 移除使用记录标题栏中的“全部类型”筛选及请求类型下拉。
- 保留类型/状态列、请求类型徽章和请求类型聚合 API 契约。
- 状态、传输和调度筛选继续可用，服务端分页与轮询后的本地过滤语义保持不变。

## 实现

- `UsageRecordsTable.vue` 删除请求类型快捷筛选、相关 Props、事件和筛选项计算。
- `Usage.vue` 删除类型筛选状态、事件处理、请求参数与轮询过滤维度。
- `useUsageData.ts` 不再加载请求类型聚合，也不再向记录接口发送 `request_type`。
- `recordFilterPolicy.ts` 只在轮询后核对状态、传输和调度三个筛选维度。

## 验证

- 使用记录相关 76 项目标 Vitest 覆盖筛选控件、请求参数、轮询过滤和类型展示回归。
- `npm run type-check`、目标 ESLint、`npm run build` 通过。
- 真实组件 fixture 检查 1024px 与 390px 布局无横向溢出；筛选操作只发送 `request_status`，请求类型参数与聚合调用均为 0。
