# 模型测试诊断工作台视觉重构

日期：2026-10-29

## 目标

- 按信息优先级重构模型测试弹窗，而不是只调整颜色。
- 让测试范围、实时执行轨迹、最终结论和请求响应形成稳定的诊断工作台。
- 保持单一弹窗、单一状态流，同时改善桌面与窄屏布局。

## 实现

- 弹窗扩展为 5xl，并采用“左侧测试范围、右侧执行与结果”的双区布局；52rem 以下自动转为纵向布局。
- 顶栏统一展示模型测试状态与实时进度，配置收起后保留端点、Key、映射摘要。
- 空闲态以“端点 → Key → 映射”的链路示意说明测试方式；运行态使用进度条、当前候选和纵向执行轨迹。
- 成功或失败结果首屏展示结论、实际 Key/模型、HTTP 和耗时；失败原因保留在结论卡内。
- 执行明细使用统一左对齐列、语义边框和紧凑表格；移动端切换为可展开卡片。
- 诊断详情改为独立的分段 Tabs 与 JSON 工具栏，点击执行记录后自动滚动到可见位置。
- 请求 ID 支持一键复制；浅色和深色主题分别调整结论卡、指标块和状态色对比度。

## 验证

- 目标 Vitest 3 个文件、5 项通过。
- `npm run type-check`、目标 ESLint、`npm run build` 通过。
- 真实组件浏览器检查 1200×900、900×640、390×844 和浅深主题，无页面或弹窗横向溢出。
- 实际验证开始、进行中、停止、成功、失败、请求 ID、执行记录选中与诊断详情滚动；结果态无“返回”，页脚操作符合状态。
