# 模型映射精确标识精简

日期：2026-10-29

## 目标

- 删除模型映射列表中精确映射行重复的“精确”徽章及其后的分隔竖线。

## 实现

- `ModelMappingTab.vue` 的精确映射行只保留“N 个映射”，不再渲染“精确”徽章和 `|` 分隔符。
- 编辑、删除按钮以及正则映射的“正则”标识保持不变。

## 验证

- `ModelMappingTab.contract.spec.ts` 2 项通过；`npm run type-check` 和目标 ESLint 通过。
- 真实组件 fixture 检查：页面不再出现“精确”或 `| N 个映射`，映射数量与编辑/删除按钮保留，页面无横向溢出。
