# README 截图

这些图片用于展示 Aether 的当前管理界面，全部基于前端真实组件和合成数据生成，不包含真实供应商名称、余额、密钥、账户、请求正文或日志。

更新截图时：

1. 使用项目已有 fixture 或隔离数据实例。
2. 将供应商、Key、模型、端点、账户和地址替换为明确的示例值。
3. 检查画面中是否出现真实域名、余额、客户端 Key、Cookie、请求头或本地路径。
4. 优先生成 WebP，保留清晰文字并控制文件大小。
5. 同步检查 README 中的图片说明和界面状态是否仍准确。
