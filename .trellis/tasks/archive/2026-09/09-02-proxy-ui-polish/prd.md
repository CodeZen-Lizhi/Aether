# 系统设置-网络代理 UI 优化

## Goal

重构系统设置中的网络代理卡片（`frontend/src/views/admin/system-settings/ProxyConfigSection.vue`）：把内联单节点表单改为「节点列表 + 编辑弹窗」模式，理清双「保存」语义，重排按钮层级，并将连通性测试结果内联持久展示。

## Background / 现状问题

1. **双「保存」语义混淆**：卡片头部「保存」保存的是系统默认代理选择（`hasChanges` 控制 enable），表单区「保存节点 / 添加节点」保存节点本身，用户无法分辨；头部按钮禁用时无解释。
2. **节点管理无总览**：多节点时只能通过「选择要管理的节点」下拉逐个切换查看，无列表总览；下拉仅在节点数 >1 时出现，引起布局跳动。
3. **按钮层级混乱**：「测试连接」「保存节点」「删除」同行左对齐，破坏性操作紧邻主操作。
4. **测试结果转瞬即逝**：延迟/出口 IP 只用 toast 展示，无法对比节点后决策。
5. **缺前端校验**：代理地址格式仅靠 placeholder 提示，非法格式提交后才暴露。
6. **文案兜底交互**：「编辑时密码留空表示保持原密码不变」依赖说明文字，而非字段自身的状态提示。

## Requirements

- R1 卡片头部保存按钮文案改为「保存默认代理」，保留现有 `loading || !hasChanges` 禁用逻辑，禁用时提供 title 提示（如「暂无改动」）。
- R2 卡片内容分为两个区块：**默认代理**（Select + 说明文字）在上，**代理节点**管理在下，用分隔线区隔。
- R3 节点管理以列表呈现：每行展示名称、在线状态 Badge、地址（`tunnel_mode ? ip : ip:port`）、区域；提供「编辑」入口；空状态展示「暂无代理节点」提示与添加入口。
- R4 添加/编辑节点使用弹窗（复用 `@/components/ui` 的 Dialog）：
  - 表单字段：名称*、代理地址*、用户名、密码、区域（与现状一致）。
  - 代理地址前端校验：必须以 `http://` / `https://` / `socks5://` 开头，非法时字段下方内联报错并禁用保存。
  - 编辑态密码字段 placeholder 提示「留空保持不变」，留空时提交不携带密码（保持现有 API 行为）。
  - 底部按钮：左侧「删除」（仅编辑态，红色 outline，保留 `confirmDanger` 确认）；右侧「测试连接」（outline）与「保存」（primary）。
- R5 「测试连接」结果内联持久展示在弹窗表单内：成功显示延迟与出口 IP，失败显示错误信息；重复测试覆盖上一次结果。
- R6 删除节点后的联动行为保持现状：清理外部模型目录缓存、清空系统默认代理选择（`cleared_system_proxy` / `cleared_external_models_proxy`）。
- R7 新增中文文案补充到 i18n 字典（`frontend/src/i18n/messages.ts` 的英文映射）。
- R8 头部「保存」disabled-until-changes 是全部设置卡片的统一模式，本任务**不改动**该全局模式，仅按 R1 澄清本卡片文案。

## Out of Scope

- 不新增/修改后端 API（`proxyNodesApi` 现有接口够用）。
- 不改动其他设置卡片的保存按钮文案（全局一致性调整如需要，另立任务）。
- 不做卡片两列布局等纯视觉大改。
- 不改动 providers 页面的 ProxyNodeSelect 组件。

## Acceptance Criteria

- [ ] AC1 网络代理卡片头部按钮文案为「保存默认代理」，默认代理未改动时禁用且有 title 提示；改动后可点击并正常保存。
- [ ] AC2 卡片内可见代理节点列表（名称/状态/地址/区域），无节点时显示空状态与添加入口。
- [ ] AC3 点击「添加节点」或某节点「编辑」打开弹窗，表单可完成创建/更新，成功后弹窗关闭、列表刷新、toast 提示（行为与现状一致）。
- [ ] AC4 代理地址缺少合法前缀时，保存按钮禁用且字段下方有内联错误；补全后可保存。
- [ ] AC5 编辑弹窗内密码留空提交时，请求不携带密码字段；placeholder 显示「留空保持不变」。
- [ ] AC6 弹窗内点击「测试连接」，结果（延迟/出口 IP 或错误）内联显示且不随时间消失。
- [ ] AC7 「删除」仅存在于编辑弹窗，点击后出现确认框；确认后联动清理逻辑与现状一致。
- [ ] AC8 新增文案在英文语言下有对应翻译（i18n 字典已补充）。
- [ ] AC9 `pnpm --dir frontend type-check` 与 `pnpm --dir frontend test:run`（含新增/更新 spec）通过。
