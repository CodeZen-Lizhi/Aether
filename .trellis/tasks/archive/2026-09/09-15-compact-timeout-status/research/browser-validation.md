# 本地浏览器核验

使用 Playwright 的 aether-timeout 会话、Vite 127.0.0.1:4175 和真实 Vue 组件。API 由 fixture 在内存模拟，无生产读取/写入；后端行为由独立 HTTP/SQLite 验收覆盖。

- request-detail-layout.html?status=retry-gap：表格“等待中”，请求链路“进行中”，失败候选仍显示 504 和180秒；整请求181秒。关闭并重新打开详情后仍为活动状态，未将候选失败锁入列表。
- status=final-failed：列表“失败”、详情“请求失败”，全程均为300.01秒，第二轮119.01秒保留在节点。点击刷新后未回退活动状态。
- provider-timeout.html：首次响应字段保留180秒、旧预算180000ms；新总期限初始继承900秒。保存600秒，重开确认600秒和“提供商配置”；清空保存，确认原始值null、生效900秒、首次180秒和旧预算不变。页面无console error。

上述为 UI 控件和事件合并流程，不能替代真实供应商响应或真实 HTTP 持久化证据。生产接口未调用。
