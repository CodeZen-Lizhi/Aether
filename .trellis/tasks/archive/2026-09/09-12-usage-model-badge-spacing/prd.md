# 修复模型名称与推理标签的间距

## Goal

使用记录中的 high/medium 等推理标签紧跟模型名称；名称换行后也不在模型列右侧留下明显空隙。

## Context

用户安装 0.1.19 后再次指出 gpt-6-astra 换成两行时 high 仍离文字太远。之前提交 1917a8ffe 已把模型行改为 w-fit，但用户截图仍有问题，不能只测试容器 class。

## Scope

- 行为位于共享 UsageModelDisplay.vue，使用记录桌面表格、紧凑卡片、请求详情均使用它。保留完整模型名称、actual model 映射、徽标内容和多标签堆叠规则。
- 首选局部排版修复；不更改表格列权重、整页字体、后端字段或其他页面布局。仅在真实调用方约束确有必要时修改调用方。
- 创建可重复运行的真实浏览器几何检查：复现截图窄模型列，以文字 Range 最后一行的可见边缘衡量标签间距，而非仅测 span 容器右沿。

## Acceptance

- [x] 修复前可复现 gpt-6-astra + high/medium 的过大文字间距；修复后单行或换行时标签紧邻名称末尾，放不下则自然续行，不独占右侧一列。
- [x] 在真实表格、紧凑卡片以及详情组件字体/容器样式的窄宽度与足够宽度检查；长模型名、映射名、多个徽标无遮挡、裁切或横向溢出。
- [x] 浏览器回归脚本明确旧代码失败、新代码通过；相关组件测试、定向 lint/type-check 通过。
- [x] 提供修复截图，按本次 APP 修复交付延续上一轮提交、push、打包授权；0.1.20 新包与 origin/codex/tauri-macos 同步，修复提交 efc4a1d8f、版本提交 c0a025b68；保留实际原生验证边界。

## Ownership

实现子代理负责组件修复、必要回归测试与最小浏览器复现；主会话负责真实调用方截图复核、spec、提交与打包。不得停止用户 APP 或修改个人使用数据。
