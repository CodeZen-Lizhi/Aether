# 统一优化窗口自适应与无横向滚动布局

## Goal

参考 CC Switch 的紧凑自适应布局，消除页面、表格、抽屉和弹窗的横向滚动，统一隐藏滚动条并保留纵向浏览；完成尺寸核验、两分支同步和客户端打包。

## Requirements

- 参考 CC Switch 的紧凑、随窗口宽度调整的布局，统一优化管理页面、表格、弹窗、抽屉及桌面入口。
- 不出现横向滚动或必须左右拖动才能看到的字段与操作；所有内容保持可访问。
- 不显示纵向滚动条；数据较多时仍可通过触控板、滚轮和键盘纵向浏览。
- 页面密度、间距、列布局适配不同窗口尺寸；不改变统计口径、数据与业务操作。
- 保留已有错误完整展示及保存成功自动关闭等行为，共用代码同步两分支，交付新的客户端安装包。

## Acceptance Criteria

- [x] 主要 8 个管理页面在 840、1024、1280、1920 像素宽度均无页面或内容区横向滚动。
- [x] 高频详情与编辑弹窗中，长名称、URL、JSON、时间线和价格配置完整可读、可操作。
- [x] 滚动条不显示，纵向内容仍可滚动到末尾，分页及底部保存按钮可用。
- [x] 字号、图表和卡片在尺寸变化后正常布局；原有关键交互回归通过。
- [x] 必要测试、类型检查、lint、真实浏览器与安装包验收通过；代码已同步并 push。

## Notes

- 用户已授权整体布局优化，并沿用此前提交、push、两分支同步与打包授权。
- 使用隔离数据验证，不改动用户真实客户端数据库和另一工作树中的 UI 工作。
