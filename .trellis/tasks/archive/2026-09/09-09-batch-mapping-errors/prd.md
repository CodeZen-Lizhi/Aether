# 修复批量模型映射提示和完整错误展示

## Goal

清理已移除单条映射入口的过时提示，保留并完整展示上游查询与批量保存错误；维持保存成功自动关闭，验证后同步两条分支并交付客户端安装包。

## Requirements

- 批量映射界面不再引导用户使用已删除的单条编辑入口。
- 上游模型查询的长错误、多 Key / 多格式错误、HTTP 状态和响应详情完整可见；部分查询失败的详情留在弹窗中供查看。
- 批量保存失败时列出每个失败客户端模型及其错误，保留待保存内容供重试；全部保存成功后自动关闭。
- 长 URL、连续字符和多行内容可换行阅读，原始错误以纯文本呈现。
- 共用功能同步到 `codex/tauri-macos` 和 `slim-personal`，提交并 push，交付包含本次修复的 macOS 安装包。

## Acceptance Criteria

- [x] 截图中的过时说明已移除。
- [x] 使用超过 100 字符且包含多个 Key 的错误复现，界面能显示最后一条错误的末尾。
- [x] 查询部分失败和批量保存多个模型失败时，无错误条目丢失。
- [x] 保存成功关闭、失败重试行为的现有回归通过。
- [x] 受影响测试、类型检查、定向 ESLint 与页面核验通过。
- [x] 两分支共用修改一致，安装包可校验。

## Notes

- 用户已授权实现、提交、push、两分支同步和打包；采用局部修复，不改变模型获取或保存的业务语义。
- 使用合成凭据和隔离测试，不写入真实客户端数据。
