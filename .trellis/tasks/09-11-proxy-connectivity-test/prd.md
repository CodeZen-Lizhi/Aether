# 增加代理连通性测试

## Goal

让用户无需进入编辑表单即可验证已保存代理节点的连通性，并保留编辑表单中对未保存配置的测试能力。

## Confirmed Facts

- `ProxyNodeEditDialog.vue` 已有「测试连接」，通过 `POST /api/admin/proxy-nodes/test-url` 测试当前填写的地址及凭据。
- 后端已有 `POST /api/admin/proxy-nodes/:id/test`，按节点读取已保存的连接信息并返回 `success`、延迟、出口 IP 或错误。

## Requirements

- 每个列表节点在「编辑」旁增加「测试」操作。
- 列表操作使用按节点 ID 的既有端点，不在浏览器读取或传输已保存密码。
- 测试中仅禁用正在测试的节点按钮，并反馈进行中状态。
- 结果使用当前编辑弹窗一致的成功/失败语义：成功可显示延迟和出口 IP；失败显示可操作错误信息。

## Acceptance Criteria

- [ ] 节点列表的每行都显示「测试」与「编辑」操作。
- [ ] 点击测试调用正确的按节点 ID 接口，且同一节点请求未完成时不可重复提交。
- [ ] 成功与失败都获得明确反馈；一个节点测试不阻塞其他节点的编辑或测试。
- [ ] 编辑弹窗原有的「测试连接」和内联结果保持可用。

## Out Of Scope

- 不改变测试探针、超时、代理 URL 校验或节点状态判定规则。
