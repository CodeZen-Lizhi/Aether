# 启动后直接进入仪表盘

用户指出正常启动仍会先显示“正在启动网关 / 客户端设置”，要求打开 Aether 后直接进入仪表盘。网关继续自动在后台启动，正常启动过程中不显示客户端设置页；设置通过菜单手动打开，启动失败仍有明确的错误处理入口。

启动期间重复点击 Dock 或再次打开应用时，应等待本次初始化完成再显示仪表盘，不能把设置页唤出来。登录自启继续后台运行，用户主动打开时再显示仪表盘。保留现有网关生命周期、数据、钥匙串、会话和权限行为。

验收：
- [ ] 客户端设置窗口初始隐藏，普通启动网关就绪后直接显示仪表盘。
- [ ] 初始化期间的重复激活不会显示设置或丢失打开仪表盘的请求。
- [ ] 后台自启保持无窗口；显式设置入口和失败提示可用。
- [ ] 相关检查通过，当前分支提交并 push，递增版本后交付新安装包。
