# 仪表盘使用趋势

## 目标

参照用户提供的 CC Switch 使用趋势，在现有仪表盘展示费用、缓存创建、缓存命中、输入、输出五条曲线。仅修改前端，复用现有统计周期，不改后端。

## 验收

- [x] 双坐标轴区分 Token 与费用，提供图例开关、明细提示及可访问的数据展示。
- [x] 支持现有小时、天、周、月粒度与时间范围；快速切换不展示旧请求结果。
- [x] 历史汇总费用保留，缺失细分明细显示空缺，不能当作零或推算到小时。
- [x] 明暗主题和 840、1024、1280、1920 px 窗口无横向溢出。
- [ ] 必要检查、隔离页面验收通过，代码同步 push 两分支并更新安装包。

## 边界

不改后端、数据库及真实客户端数据；不恢复已删除的月度健康区。
