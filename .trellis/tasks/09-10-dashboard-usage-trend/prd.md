# 仪表盘重整与使用趋势

## 目标

结合用户提供的两个软件统计页，重新组织 Aether 仪表盘的指标、视觉层级与布局。保留满意的今日指标，增加全部历史累计 Token、今日平均响应及每小时缓存面积趋势，减少重复信息和无效留白。只改前端，复用现有后端接口及项目组件。

## 页面结构

- 历史累计区：突出精确累计 Token；辅助展示累计请求、费用、实际结算和首次有数据日期。包含已导入并保留的历史汇总，不受趋势筛选影响。
- 今日概览：请求及成功率、Token 及输入输出缓存说明、费用及实际结算、最近 60 秒 RPM / TPM、今日平均响应。平均响应包含成功与失败请求，使用秒并保留两位小数。
- 使用趋势：默认今天、按小时；费用、缓存创建、缓存命中、输入、输出五条曲线，缓存命中填充面积。周期与粒度控件放在图表头部，精确数值可折叠展开。
- 用量分布：模型与提供商的紧凑排行，可按 Token / 费用 / 请求排序；保留真实名称、历史缺失说明并支持展开完整列表。

## 验收

- [x] 全部历史累计包含原始记录与保留汇总且不重复相加，累计 / 今日 / 筛选周期互相独立。
- [x] 今日平均响应为请求样本的正确平均秒数，无请求、缺失数值、加载失败分别处理，独立重试。
- [x] 默认今天按小时，Token 与费用采用双坐标轴，缓存命中面积曲线、图例开关和精确明细可用。
- [x] 历史每日费用保留，缺失 Token 明细留空；小时视图不推算每日总量。
- [x] 模型 / 提供商按所选指标排序、默认前五名且可展开，缺失部分不伪装成真实名称。
- [x] 明暗主题、中英文、840 / 1024 / 1280 / 1920 px 页面及展开明细均无横向溢出。
- [ ] 完成必要检查和独立审查，同步 push 两分支，更新并校验 macOS 安装包。

## 范围

沿用项目颜色、字体、Card 和 Chart.js，无新增依赖。不添加平台拆分或请求日志，不恢复月度健康区，移除重复成本图和默认展开的每日大表。不改后端、数据库或真实客户端数据。
