# 使用趋势验证

## 现有接口与实现边界

- `/api/admin/stats/time-series` 已返回五类数值和小时 / 天 / 周 / 月时间桶，无后端改动或新增依赖。
- 该接口只读原始 usage；前端将历史每日费用合并到天 / 周 / 月视图，明细不足的 Token 使用 null，不把缺失当零；小时视图不分摊历史每日费用。
- 输入 Token 沿用上游原始口径，部分格式包含缓存。在展开数据中明确提示各项不能直接相加。
- 时间标签已是请求时区，直接显示日期和时分，避免二次偏移。
